# vuln-lab

`dotnet/` is a minimal .NET console app used to test reachability analysis for vulnerable dependencies. It references two packages with known CVEs: `Newtonsoft.Json` 12.0.1 (GHSA-5crp-9r3c-p9vr), whose `JsonConvert` API is actually called from `Program.cs`, and `System.Text.Encodings.Web` 4.5.0 (GHSA-24c2-23r3-8vpr), which is declared but never imported or used. A correct reachability check should flag the former as reachable and the latter as not.

`js_reachability/` is a small JS app (express API, client with vue/svelte/typescript, webpack and babel configs, a coffee script) used to test reachability analysis for npm dependencies. Each vulnerable package is used through a different way of importing it, from plain `require` to `.mjs`/`.cjs` modules, chains through other dependencies and loader names in webpack and babel configs, and some appear only in comments or strings.

`vb_net/` is a small ASP.NET app in VB.NET used to test call tracing for SAST findings. Each controller action passes request input to a `Sub` that uses it in a file path (path traversal), and each call uses a different VB syntax: an argument list split across lines (`ReportsController`), a method inherited from a base class and called on a subclass-typed variable (`ExportController`), and a variable declared with `Dim x As New Foo()` (`BackupController`). A correct trace links each controller action to its file call.
